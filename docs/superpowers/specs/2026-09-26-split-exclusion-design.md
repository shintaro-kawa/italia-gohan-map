# 割り勘除外 + 精算サマリー 設計 (D-036)

日付: 2026-09-26 / 状態: 承認済み (「精算からだけ除外 (合計には含む)」を選択)

## 課題

旅行後の精算で、個人的な支出や片方負担分を割り勘計算から外したい。
現在の予算カードは支払者別の合計を出すだけで、除外手段も差額計算もない。

## 設計

### データ

- `ItineraryItem.splitExcluded?: boolean` を追加 (未設定 = 割り勘対象)
- `api/sync-itinerary.ts` の `validateWrite` に通す (true のときのみ保持、false は省略で表現 —
  merge は id 単位の丸ごと置換 (last-write-wins) なので省略で解除が伝播する)

### UI

1. 旅程カードの金額行にトグルボタン: 「🚫 割り勘から外す」⇄「↩ 割り勘に戻す」。
   押すと `updatedAt` 更新 → ローカル保存 + 同期キュー (既存の編集保存と同じ経路)。
   除外中は「割り勘対象外」バッジ表示。SSR カード (ビルド時シード) にも同じボタンを出す
2. 編集モーダル「💴 金額・清算」セクションにチェックボックス「割り勘の対象外にする」
3. 予算カードの「支払者別」→「精算 (割り勘)」に拡張:
   - 割り勘対象合計 (通貨別) + 「除外 N 件」注記
   - 支払者ごとの支払済額 (従来通り、ただし除外分を差し引いた対象のみ)
   - 円換算で 1 人あたりと各自の過不足。支払者がちょうど 2 人なら「A → B ¥X」を 1 行表示
   - 金額はあるが支払者未設定の対象アイテムは差額計算に含めず「⚠ 支払者未設定 …」と警告

### 付随修正 (既存バグ)

`updateTotals` の重複排除が `[...inline, ...private]` 順でビルド時シードを優先しており、
シード由来アイテム (EK319 等) への編集・除外トグルが合計に反映されない。
`[...private, ...inline]` 順 (同期済みデータ優先) に修正。

### 総額の扱い

旅程合計・種別別・円換算は従来通り**全アイテム** (除外分も含む)。除外が影響するのは精算セクションのみ。

## テスト

ビルド通過 + 本番バンドルにトグルコードが載ったことを確認。
実データ (28 件) での精算表示はユーザーがブラウザで確認。
